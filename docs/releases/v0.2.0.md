# ChikaBell v0.2.0

2026-10-15。v0.1.3からAIで地点を探して登録する機能を追加し、候補版v0.2.0-rc1から地点追加とAI検索の画面構成を見直したリリースです。

## 変更内容

- 本人のChatGPTプランを使ったアプリ内検索、ChatGPTアプリへの依頼文コピー、JSONでの結果取り込みを追加。AIが出した座標だけに頼らず、住所検索から別途位置を確認。
- 登録地点画面の「地点を追加」に入口をまとめ、「AIで探す」「自分で入力する」を選ぶ構成へ変更。
- AI検索を条件入力と候補確認・登録の2画面に整理。検索範囲、詳細条件、接続、場所の確認、通知設定を必要時に開くシートへ移動。
- 文字入力中も主要ボタンを押せる配置に変更。JSON本文を通常は折りたたみ、貼り付けや編集のあとに取り込み操作が隠れないよう改善。
- 候補確認の画面から直接登録できるようにし、別の取り込みプレビューで同じ内容を再確認する操作を解消。
- 保存済み接続の確認とモデル選択の引き継ぎを追加。接続処理や検索失敗・キャンセルで確認中の候補と編集内容を保持。
- 白背景・深緑・濃い本文を基調に、入力欄と選択状態を整理。
- AIとファイル取り込みの登録処理を共通化。保存直前とトランザクション内で重複・有効件数を検証し、保存成功と通知設定の失敗を区別。

## 検証

- アプリJVMテスト216件、SIWC protocolテスト14件。
- UIテスト9件と登録トランザクションのテスト7件を変更箇所で検証。入口統合後は新しい追加メニューを経由して最終登録へ進むテストを再確認。
- 360dp相当の幅、文字200%、長いJSON、実際のソフトウェアキーボード表示中の主要操作を隔離エミュレーターで確認。
- lint、正式署名ビルド、既存版との署名一致を確認。
- Pixel 10a / Android 17で、画面改良版のデータ保持更新・起動・回転設定の保持を確認。ユーザーから画面の使いやすさの改善を確認。公開用v0.2.0も同じ署名で更新し、端末APKと公開用APKのSHA-256一致を確認。

公開用の版番号はversionName 0.2.0 / versionCode 8です。公開用ビルドと公開物の整合はGitHub Releaseの添付APKとSHA256SUMS.txtで確認できます。

## 対応環境と既知の制限

- Android 10（API 29）以上。実機確認済みはPixel 10a / Android 17のみ。
- 新たに取り込んだ地点での自然な背景通知・ANR非再発、接続の期限更新・複数アカウント・解除、Web検索の個別完了表示などは実機確認を継続中。
- 位置情報や通知はAndroid・Google Play services・精度・省電力設定に依存し、即時性や確実性を保証しません。
- アプリ内検索には利用者自身のChatGPTプラン・利用枠・権限・OpenAIの提供条件が適用されます。AIが挙げた施設の実在・営業状況・位置は、出典と地図で確認してください。
- 保存済み地点や通知履歴をChatGPTへ自動送信せず、通常の有料APIへ自動で切り替えません。
