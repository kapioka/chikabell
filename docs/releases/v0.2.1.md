# ChikaBell v0.2.1

## 変更内容

- 「地点を追加」「データ管理」「AIで探す」から同じJSON・CSV取り込み画面を開けます。取り込みを閉じるか登録を完了すると、元の画面に戻ります。
- データ管理で「追加する」と「書き出す」を分けました。バックアップJSONやPCで編集したCSVは「JSON・CSVから追加」で読み込めます。
- 読み込みエラーには原因と次の操作を表示します。確認画面から戻っても、貼り付けたJSONは残ります。
- Room、Google Play services Location、Kotlin関連のビルド設定、Coroutines、CIの依存関係を更新しました。

versionName 0.2.1 / versionCode 9。Android 10（API 29）以上に対応します。

## 自動検証

- アプリJVMテスト218件、SIWCテスト14件、デバッグlintとビルドが成功しました。
- Android 15の隔離エミュレーターで29件が成功しました。取り込み画面の往復、Roomの移行と取り込み時のデータ保全、位置確認サービスとGeofence受信を含みます。
- アプリのRoomスキーマに変更はありません。

## 実機で確認する項目

- ファイル選択をキャンセルすると取り込み画面に戻り、その画面を閉じると開いた元の画面に戻ります。
- バックアップJSONと編集済みCSVを選び、追加を確定する前に候補や重複を確認できます。既存地点は保持したまま追加します。
- 実際の移動による背景通知は、位置情報の許可、測位精度、端末の省電力設定などの影響を受けます。
