# ちかベル AI一括登録CSV仕様

```yaml
spec_version: 1
format: csv
app_min_version: 0.1.2
```

この文書は、ChatGPTなどのAIが「ちかベル」へ一括インポートできるCSVを生成するための正本仕様です。

AIは、この文書を取得できない場合や内容を最後まで確認できない場合、過去の知識や推測だけでちかベル用CSVを生成しないでください。ユーザーに仕様文書の貼り付けまたはファイル提供を依頼してください。

## AIへの基本指示

1. ユーザーが指定した目的地、カテゴリ、好み、避けたい条件、件数を優先して候補地点を選ぶ。
2. Web検索等を利用できる場合、店名・所在地・緯度経度・営業状況・公式URL等を信頼できる情報源で確認する。
3. 緯度経度を確認できない地点を推測で作らない。不確実な地点は除外するか、不確実であることをCSV外でユーザーに明示する。
4. 同じ地点や同一URLを重複登録しない。
5. 最終出力前に、この文書の「最終検証」を全行に対して実施する。
6. ファイル生成が可能な環境では、説明文だけでなく実際のCSVファイルを出力する。

## 文字コードとCSV形式

- 文字コード: UTF-8 BOM付き
- 改行: CRLF推奨
- 1行目はヘッダー
- カンマ、ダブルクォート、改行を含む値はRFC 4180相当のCSV引用規則で正しくエスケープする
- CSVファイル内に説明文、Markdown、コードフェンスを混在させない
- 1ファイル最大1000地点
- ファイルサイズは2MB相当を超えない

## ヘッダー

次の12列をこの順序で出力してください。

```text
id,name,latitude,longitude,radiusMeters,message,loiteringDelaySeconds,cooldownMinutes,transitionType,enabled,sourceUrl,tags
```

## 各列の仕様

| 列 | 必須 | 仕様 |
| --- | --- | --- |
| `id` | 新規登録では空欄 | AIが新規地点を作る場合は空欄にする |
| `name` | 必須 | 1〜100文字。店舗・施設の正式名称を優先 |
| `latitude` | 必須 | `-90.0`〜`90.0` の数値 |
| `longitude` | 必須 | `-180.0`〜`180.0` の数値 |
| `radiusMeters` | 必須 | 100〜5000。通常の店舗は250〜500程度を目安にする |
| `message` | 必須 | 500文字以内。なぜ保存したか、何を試したいか等を簡潔に書く |
| `loiteringDelaySeconds` | 必須 | 15〜3600。通常は60を推奨 |
| `cooldownMinutes` | 必須 | 0〜43200。通常は720を推奨 |
| `transitionType` | 必須 | 必ず `DWELL` |
| `enabled` | 必須 | `true` または `false`。通常は `true` |
| `sourceUrl` | 任意 | 可能なら公式サイト、公式店舗ページ、信頼できる案内ページ。確認できない場合は空欄 |
| `tags` | 任意 | `|` 区切り。1地点最大5個。1タグ最大30文字 |

## タグのルール

- 1地点につき最大5個
- 同じ意味・同じ表記のタグを重複させない
- `#` は付けない
- 地域、カテゴリ、特徴、用途、優先度など、後から探すのに役立つタグを優先する
- 例: `福岡|酒蔵|日本酒|試飲|優先A`
- アプリ全体のタグ種類上限は50。AIが既存登録状況を知らない場合は、新規タグの種類を必要最小限にする

## 重複を避ける

ちかベルは、既存地点との重複判定に次の情報を利用します。

- 同じ `id`
- 同じ `sourceUrl`
- 同じ名称かつ約50m以内の地点

AIは、同じ店舗の別表記や同一店舗ページを複数行にしないでください。

## 件数に関する注意

- CSV自体は最大1000地点まで扱える
- 有効地点は既存地点と合計して最大100地点
- AIが現在の登録数を知らない場合、大量の地点をすべて `enabled=true` にしない。通常のおすすめリストでは100件未満に抑える

## 情報の信頼性

- 実在確認できない店舗・施設を創作しない
- 閉店・移転の可能性がある場合は、できる限り現在情報を確認する
- 緯度経度は店名や住所からの推測だけで断定せず、確認できる情報を使う
- `sourceUrl` は検索結果ページより公式ページを優先する
- ユーザーが避けたい食品、設備条件、予算等を指定した場合、`message` に注意点を残してよい

## プライバシー

公開用の例や共有用CSVに、個人宅、勤務先、非公開施設など利用者個人を特定し得る地点を勝手に含めないでください。

## 最終検証

CSVファイルを出力する前に、全行について次を確認してください。

- [ ] ヘッダーが指定された12列である
- [ ] `name` が1〜100文字
- [ ] `message` が500文字以内
- [ ] 緯度経度が数値かつ範囲内
- [ ] `radiusMeters` が100〜5000
- [ ] `loiteringDelaySeconds` が15〜3600
- [ ] `cooldownMinutes` が0〜43200
- [ ] `transitionType` が全行 `DWELL`
- [ ] `enabled` が `true` または `false`
- [ ] タグが1地点5個以下
- [ ] 各タグが30文字以下
- [ ] 同じ地点・同じ `sourceUrl` を重複させていない
- [ ] CSVの引用符・カンマ・改行が正しくエスケープされている
- [ ] UTF-8 BOM付きで保存されている
