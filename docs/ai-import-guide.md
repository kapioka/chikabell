# AIで地点をまとめて登録する

v0.2.0では、アプリ内のChatGPT検索、ChatGPTアプリで探してJSONを持ち帰る方法、従来のCSV取り込みを利用できます。保存済み地点や通知履歴をChatGPTへ自動送信することはありません。

## アプリ内で探す

1. 登録地点画面で「地点を追加」→「AIで探す」を選ぶ
2. 探したい場所、範囲、希望条件を入力する。件数やモデルは「詳細条件」で変更できる
3. 未接続の場合はChatGPTに接続し、検索画面へ戻る。接続しただけでは検索を送信しない
4. 「ChatGPTで検索」を押す。現在地を選んだ場合は、取得した位置を確認して「現在地も送って検索」を押す
5. 候補の出典と地図を見比べ、登録する場所と位置を選ぶ。位置候補が複数ある場合は「場所を確認」で1つ選ぶ
6. 必要に応じて「通知設定」で半径・メモ・タグを編集し、「選択したN件を登録」を押す

本人のChatGPTプラン・利用枠・権限・OpenAIの提供条件が適用されます。「利用状況」からChatGPT側の状態を確認できます。住所検索で位置を確認できない候補は除外されるため、Googleマップ共有や手動入力で確認してください。

## ChatGPTアプリで探す・JSONを取り込む

検索画面の「別の方法で探す・結果を取り込む」から「ChatGPTアプリで探す」を選ぶと、入力条件を使った依頼文をコピーしてChatGPTを開けます。ChatGPTで送信し、結果のJSON本文をコピーして戻ってください。

「結果を取り込む」→「コピーしたJSONを貼り付ける」→「取り込む場所を確認」で候補を開きます。長い本文は通常折りたたまれ、「JSON本文を入力・編集」で確認できます。貼り付けは10万文字以内です。

「設定」→「データ管理」→「JSONを貼り付ける・ファイルを開く」からも取り込めます。JSON・CSVファイルは2MB相当以内です。対応JSONは[Import Contract](ai-import-contract.md)を参照してください。

取り込み前に場所・位置・通知を確認します。既存地点の削除・上書きはせず、重複・件数・入力内容を保存直前にも検証します。

## 従来のCSV方式

以下は、外部のAIに依頼してCSVを持ち帰る方式の説明です。

### 1. AIへ依頼する

[`ai-import-prompt.md`](ai-import-prompt.md) にコピペ専用Promptを用意しています。

1. コードブロックをコピーする
2. `目的地`、`探したいもの`、`好み`、`避けたいもの`、`件数` を書き換える
3. ChatGPTなどのAIへ送る

Promptには最新の [`ai-import-spec.md`](ai-import-spec.md) を取得して従う指示が含まれているため、CSV列やタグ上限などの詳細を毎回入力する必要はありません。

旅行以外にも、次のような使い方ができます。

- 出張先で寄れそうな飲食店や書店
- ドライブ中に思い出したい道の駅や温泉
- 子どもと行ける公園や施設
- 気になっているラーメン店やカフェ
- 酒蔵、醸造所、直売所めぐり

### 2. AIが作ったCSVを保存する

AIがファイルを生成できる場合は、そのCSVを端末へ保存します。

CSVの正本仕様は [`ai-import-spec.md`](ai-import-spec.md) です。正常な最小例は [`ai-import-example.csv`](ai-import-example.csv) です。

### 3. ちかベルでインポートする

ちかベルのCSVインポートからファイルを選びます。

インポート前にプレビューが表示されるので、件数・重複・エラーを確認してから適用してください。

### 4. 登録後に地点を確認する

AIが選んだ情報は誤っている場合があります。特に次を確認してください。

- 店舗が現在も営業しているか
- 緯度経度が店舗位置と一致しているか
- 通知半径が広すぎないか
- タグやメモが自分の用途に合っているか

## AIが仕様URLを読めない場合

AIによってはWebアクセスができない、またはURLを自動取得できない場合があります。

その場合は推測でCSVを作らせず、次のいずれかを行ってください。

1. [`ai-import-spec.md`](ai-import-spec.md) を開いて内容をAIへ貼り付ける
2. 仕様ファイルを保存してAIへアップロードする
3. Webアクセスできる別のAI環境を利用する

## よくあるインポート失敗

### タグが多すぎる

1地点に付けられるタグは最大5個です。AIへ必ず仕様書を読ませてください。

### 有効地点が多すぎる

有効な地点は、既に登録されている地点を含めて最大100件です。大量登録する場合は一部を `enabled=false` にしてから読み込んでください。

### 同じ場所が重複する

同じ `sourceUrl`、または同じ名称で約50m以内の地点は重複として扱われます。

### 緯度経度が違う

AIは地点情報を誤る場合があります。重要な地点は、インポート後に外部地図で位置を確認してください。

## この方式にしている理由

このCSV経路ではアプリ内のChatGPT接続を使わないため、次の特徴があります。

- AIサービス用APIキーをちかベルへ登録する必要がない
- 開発者側でAI利用料を負担しない
- 特定のAIサービスへ固定されない
- ちかベルが保存地点をAIへ自動送信しない
- AI側の仕様変更があっても、CSVという単純な受け渡しを維持しやすい

## 仕様更新について

AI向けの出力条件は [`ai-import-spec.md`](ai-import-spec.md) を正本とします。

タグ上限やCSV列などが将来変更された場合、古いPromptをコピーし直すのではなく、AIが最新の仕様書を参照することで追従できる設計です。

コピペ用Prompt自体を変更する必要がある場合は [`ai-import-prompt.md`](ai-import-prompt.md) だけを更新します。
