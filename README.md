# ちかベル (ChikaBell)

ちかベルは、目的の店舗へ出かけるためのアプリではありません。
普段のお出かけ先で、以前ネットで見かけて保存しておいた店舗や場所が近くにあることを、そっと思い出させるAndroidアプリです。

通知の即時性や確実性よりも、外出中の偶然の気づきをゆるく増やすことを目的としています。
「必ず知らせる」ための道具ではなく、「近くまで来ていたことに気づけたら少しうれしい」くらいの、ゆるい使い方を想定しています。

## v0.2.0の変更点

普段のお出かけ中に、場所を探して登録しやすいように画面構成を見直しました。

- 地点の追加方法を、登録地点画面の「地点を追加」にまとめました。「AIで探す」と「自分で入力する」を選べます。
- AI検索を「条件を入力して探す」「場所を確認して登録」の2画面に整理しました。範囲、詳細条件、アカウント、通知設定は必要なときだけ開きます。
- 文字入力中も検索・取り込み・設定の操作ボタンが見える配置にしました。長いJSONは折りたたんで確認でき、本文がボタンを押し出しません。
- 検索結果で場所と通知設定を確認したあと、その画面から登録できます。ほぼ同じ内容を別の取り込み画面でもう一度確認する操作を減らしました。
- 保存済みのChatGPT接続を開いたときに確認し、モデル選択を引き継ぎます。接続の確認や検索の失敗で、確認中の候補を消さないようにしました。
- 白背景と深緑を基調に、文字・入力欄・選択状態を見分けやすくしました。

背景通知や接続更新などの実機確認は継続中です。更新内容と検証範囲は[リリース記録](docs/releases/v0.2.0.md)を参照してください。

## 主な機能

- 権限・端末設定の現在状態、推奨設定、要対応項目をまとめて案内
- 地点の追加・編集・削除
- Googleマップ等の共有テキスト・座標受信（Googleマップ短縮URLはGoogleのHTTPSサーバーで展開）
- 半径、滞在秒、再通知間隔の地点別設定とテンプレ
- 通知時の端末現在地・精度・登録地点からの距離を履歴へ記録
- 画面OFF・バックグラウンドでのGeofence監視
- 通知距離の外側で開始する短時間の位置確認と、同一接近中の重複通知抑制
- 通知からの12時間休止、複数地点の通知集約、外部地図表示
- 通知・検証履歴
- 再起動・アプリ更新後の監視復元と診断
- JSONバックアップ・復元
- UTF-8 BOM付きCSV入出力と安全なimport preview
- 検索条件をChatGPTへコピー・共有し、JSONを貼り付けて選択取り込み
- 本人のChatGPT接続によるアプリ内地点検索、住所からの位置確認、承認プレビュー

## AIで地点をまとめて登録

登録地点画面の「地点を追加」から「AIで探す」を選びます。

1. 探したい場所、エリア、希望する条件を入力する
2. 必要ならChatGPTに接続し、「ChatGPTで検索」を押す
3. 候補の住所・出典・地図を見比べ、登録する場所と位置を選ぶ
4. 必要なら通知半径・メモ・タグを編集し、「選択したN件を登録」を押す

端末の現在地を使う場合は「探す範囲」で取得した位置を確認し、「現在地も送って検索」で送信します。接続には利用者自身のChatGPTプラン・利用枠・提供条件が適用されます。

ChatGPTアプリで探す方法やJSONの貼り付けは「別の方法で探す・結果を取り込む」から選べます。JSON・CSVファイルの読み込みとバックアップは「設定」の「データ管理」からも利用できます。

対応JSONは[地点Import Contract](docs/ai-import-contract.md)、検索・出力の手順は[Workflow](docs/ai-place-search-workflow.md)を参照してください。アプリ内検索はAndroidの住所検索で別途位置を確認するため、位置候補を取得できない場所はGoogleマップ共有・手動確認を使ってください。

従来のCSV方式も利用できます。[コピペ用Prompt](docs/ai-import-prompt.md)で条件を指定し、AIが作ったCSVを取り込みプレビューで確認して登録します。[公式CSV仕様](docs/ai-import-spec.md)、[操作ガイド](docs/ai-import-guide.md)、[架空の形式例](docs/ai-import-example.csv)を参照してください。

## 権限

- 正確な位置情報: 地点との距離を判定するため
- バックグラウンド位置情報: 画面OFF・アプリ非表示時もGeofence通知を受けるため
- 通知: 接近通知を表示するため
- 活動認識: 徒歩・自転車・車両を端末内で判別し、短時間確認の測位間隔を調整するため
- 位置情報のフォアグラウンドサービス: Geofence受信後の確認中だけ測位を継続し、完了時に停止するため
- 起動完了受信: 端末再起動後にGeofence監視を復元するため

本アプリはGoogleマップ短縮URLの展開と、利用者が選択したChatGPT接続・地点検索に`INTERNET`権限を使用します。検索は確認した条件だけを送信し、端末現在地は明示選択・承認した場合だけ含めます。保存済み地点や通知履歴はChatGPTへ自動送信しません。独自サーバー・広告・解析SDKは使用しません。接近検知には端末のGoogle Play servicesを使用します。詳細は[プライバシー説明](PRIVACY.md)を参照してください。

## プライバシーとバックアップ

地点、座標、メモ、通知履歴は端末内のRoomデータベースへ保存します。Android自動バックアップは無効です。機種移行や保全には、アプリ内のJSONバックアップを利用してください。

JSON/CSVには座標やメモが含まれます。公開リポジトリ、Issue、チャット、共有ストレージへ誤って添付しないでください。詳細は[PRIVACY.md](PRIVACY.md)を参照してください。

## 既知の制限

- Geofence通知はAndroid、Google Play services、位置精度、バッテリー設定に依存し、遅延したり通知されなかったりする場合があります。
- 本アプリは確実な到着通知、業務上のリマインダー、安全管理など、通知漏れが問題になる用途には適していません。
- Pixel 10a / Android 17以外の端末、OS、メーカー独自の省電力設定では動作確認していません。対応OSの条件を満たしていても、インストール、起動、バックグラウンド動作、通知を保証しません。
- 短縮Maps URLはGoogle Maps関連ホストへ接続して展開しますが、応答形式や通信状態によって座標を取得できない場合は手入力が必要です。
- アプリを強制停止すると、ユーザーが再度起動するまでAndroidが背景処理を止めます。
- 複数地点通知の「地図を見る」は、最寄り候補をGoogleマップで開きます。追加測位やMaps SDK/APIキーを必要とするアプリ内地図は意図的に持ちません。
- Android 12以降では、`allowBackup=false`でも端末メーカーによって端末間転送が許可される場合があります。

## 開発・検証

次回更新に向けて選定した作業は[ロードマップ / ToDo](docs/roadmap.md)を参照してください。

前提:

- JDK 17
- Android SDK 37（compileSdk。minSdk 29 / targetSdk 36）
- Windows PowerShell（このリポジトリの既存検証環境）

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

近接通知の実機検証は[`docs/nearby_notification_validation.md`](docs/nearby_notification_validation.md)に分離しています。

release候補の検証:

```powershell
.\tools\build_release.ps1
```

初回は `Setup-Signing.cmd` で既存鍵とパスワードを登録し、以後は `Build-Release.cmd` を使います。`build_release.ps1`は登録済みの暗号化署名設定が不足している場合、ビルド前に失敗し、`dist/`へAPKを作成しません。署名後のAPKを`apksigner`で検証できた場合だけ配布物とSHA-256を生成します。署名方法は[docs/github_release.md](docs/github_release.md)を参照してください。
