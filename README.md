# ちかベル (ChikaBell)

ちかベルは、目的の店舗へ出かけるためのアプリではありません。
普段のお出かけ先で、以前ネットで見かけて保存しておいた店舗や場所が近くにあることを、そっと思い出させるAndroidアプリです。

通知の即時性や確実性よりも、外出中の偶然の気づきをゆるく増やすことを目的としています。

## 現在の状態

- バージョン: `0.1.0`
- 対応OS: Android 10（API 29）以上
- 実機検証: Pixel 10a / Android 17
- 配布方針: ソースコードと署名済みAPKをGitHubで公開予定。Play Store公開予定なし
- サポート方針: 動作保証なし。IssueおよびPull Requestは受け付けない

## 主な機能

- 地点の追加・編集・削除
- Googleマップ等の共有テキスト・座標受信（Googleマップ短縮URLはGoogleのHTTPSサーバーで展開）
- 半径、滞在秒、再通知間隔の地点別設定とテンプレ
- 通知時の端末現在地・精度・登録地点からの距離を履歴へ記録
- 画面OFF・バックグラウンドでのGeofence監視
- 通知距離の外側で開始する短時間の位置確認と、同一接近中の重複通知抑制
- 通知からの12時間休止、複数地点の通知集約、外部地図表示
- 通知・検証履歴
- 再起動・アプリ更新後の監視復元と診断
- JSONバックアップ・復元
- UTF-8 BOM付きCSV入出力と安全なimport preview

## 権限

- 正確な位置情報: 地点との距離を判定するため
- バックグラウンド位置情報: 画面OFF・アプリ非表示時もGeofence通知を受けるため
- 通知: 接近通知を表示するため
- 活動認識: 徒歩・自転車・車両を端末内で判別し、短時間確認の測位間隔を調整するため
- 位置情報のフォアグラウンドサービス: Geofence受信後の確認中だけ測位を継続し、完了時に停止するため
- 起動完了受信: 端末再起動後にGeofence監視を復元するため

本アプリはGoogleマップ短縮URLを展開するために`INTERNET`権限を使用します。通信先はGoogle Maps関連のHTTPSホストに限定し、独自サーバー・広告・解析SDKは使用しません。保存済み地点や通知履歴をアプリ独自に外部送信する機能はありません。接近検知には端末のGoogle Play servicesを使用します。

## プライバシーとバックアップ

地点、座標、メモ、通知履歴は端末内のRoomデータベースへ保存します。Android自動バックアップは無効です。機種移行や保全には、アプリ内のJSONバックアップを利用してください。

JSON/CSVには座標やメモが含まれます。公開リポジトリ、Issue、チャット、共有ストレージへ誤って添付しないでください。詳細は[PRIVACY.md](PRIVACY.md)を参照してください。

## 既知の制限

- Geofence通知はAndroid、Google Play services、位置精度、バッテリー設定に依存し、遅延したり通知されなかったりする場合があります。
- 本アプリは確実な到着通知、業務上のリマインダー、安全管理など、通知漏れが問題になる用途には適していません。
- 短縮Maps URLはGoogle Maps関連ホストへ接続して展開しますが、応答形式や通信状態によって座標を取得できない場合は手入力が必要です。
- アプリを強制停止すると、ユーザーが再度起動するまでAndroidが背景処理を止めます。
- 複数地点通知の「地図を見る」は、最寄り候補をGoogleマップで開きます。追加測位やMaps SDK/APIキーを必要とするアプリ内地図は意図的に持ちません。
- Android 12以降では、`allowBackup=false`でも端末メーカーによって端末間転送が許可される場合があります。

## 開発・検証

前提:

- JDK 17
- Android SDK 36
- Windows PowerShell（このリポジトリの既存検証環境）

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

近接通知の実機検証は[`docs/nearby_notification_validation.md`](docs/nearby_notification_validation.md)に分離しています。

release候補の検証:

```powershell
.\tools\build_release.ps1
```

`build_release.ps1`は署名環境変数が不足している場合、ビルド前に失敗し、`dist/`へAPKを作成しません。署名後のAPKを`apksigner`で検証できた場合だけ配布物とSHA-256を生成します。署名方法は[docs/github_release.md](docs/github_release.md)を参照してください。

## インストール

GitHub Releasesから署名済みAPKを取得し、Androidの「不明なアプリのインストール」を明示的に許可して導入します。更新版は前版と同じ署名鍵で署名されている必要があります。
