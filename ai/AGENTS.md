# ChikaBell AI import entry

This is the public data-contract entry for users asking an AI to find places for ChikaBell. It is separate from the repository development instructions.

Read [Import Contract](../docs/ai-import-contract.md), its linked JSON Schema and search workflow before producing data. Do not infer a compatible format when any required specification is unavailable. Explain the failure and stop.

For existing CSV/file users, [CSV specification](../docs/ai-import-spec.md) remains the authority. Do not create a second location format.
